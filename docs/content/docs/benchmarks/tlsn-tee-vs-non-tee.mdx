## Source Material

- Repository: [`livylabs/tlsn`](https://github.com/livylabs/tlsn)
- Branch: `benchmark`
- Metric:
  `NOTARIZATION_MS`
- Sample size:
  10 runs per mode

These measurements were collected from the benchmark branch. The implementation docs elsewhere use `tee_dev` as the source of truth.

## Test Matrix

- `TEE no verify`:
  notarization with TDX attestation requested, excluding local quote verification time.
- `No TEE`:
  normal TLSN notarization without the extra TDX attestation message.

## Methodology

Each row below is one notarization run. The values are elapsed milliseconds for the notarization phase only, not full end-to-end request time.

## Overhead

| Comparison | Average overhead | Percent overhead |
| --- | ---: | ---: |
| TEE no verify - No TEE | +103.9 ms | +5.97% |

## Notes

The No TEE series includes one high-latency outlier at run 3 (`3320 ms`). That outlier raises the No TEE average and P90, so the median comparison is also useful when reading this result.
